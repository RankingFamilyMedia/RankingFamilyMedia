# **App Name**: JungleBeats Marketplace

## Core Features:

- Beat Catalog Display: Display a catalog of beat instrumentals with details like title, genre, BPM, preview URL, and price.
- Audio Preview: Allow users to listen to low-quality previews of beats.
- Custom Beat Request Form: Provide a form for custom beat requests and submit to admin.  Store the request details for tracking.

## Style Guidelines:

- Primary color: Vibrant green (#A3E47B) to evoke the lively, natural energy of the jungle.
- Background color: Light off-white (#F2F4F3), a desaturated, bright tint of the primary hue.
- Accent color: Warm yellow (#E4D97B), to complement the primary green.
- Font: 'PT Sans', a humanist sans-serif for headlines and body, blending modernity with warmth for readability.
- Use modern, minimalist icons to represent different music genres and beat attributes (BPM, etc.).
- Subtle transitions and loading animations to enhance user experience.
